# Ters Yön Asansör Psikoloğu

## Resmi Olmayan Ama Çok Resmi Duran Klinik

Bu depo, insanlığın en ihmal edilen ruh sağlığı krizini tedavi etmek için kurulmuştur: **asansör düğmesine basmadan önceki 1.4 saniyelik varoluşsal boşluk.**

Bilim henüz bu boşluğu ölçemedi. Biz ölçmedik. Sadece teşhis koyduk. Teşhis ücretsizdir, merdiven ücretlidir.

## Bu Yazılım Ne Yapar?

1. Hangi kata basmak üzere olduğunuzu sorar.
2. Kabinin ruhunu dinler (yaklaşık 1.6 saniye).
3. Size rastgele ama şaşırtıcı derecede isabetli bir teşhis söyler.
4. Hayatınızı düzeltmez.
5. Asansör yine gelir. Siz yine aynısınız.

## Kurulum

```bash
python3 asansor_psikologu.py
```

Başka bir şey kurmayın. Kurarsanız asansör küser.

## Klinik Protokolü

- Kapıya sığmayan duygular kabine alınmaz.
- Aynı düğmeye üç kez basmak acil seans sayılır.
- Müzik çalıyorsa düşünmek yasaktır.
- 13. kat yoktur. Vardır ama konuşulmaz.
